# PHASE 3 UI Contract

Extend D086 workspace navigation and the existing authenticated shell. Use the existing Player management entry and the season-scoped registrations area from the [screen map](../../../context/design/architecture.md#derived-frontend-screen-map). Render Vietnamese labels and guidance, clear required fields, Loading/Empty/Error states and scoped search/pagination. The backend controls access to each route, action and record.

- **UC08**: List by season/club/state, show BM1 and its exact received/submitted version, and distinguish timely receipt, approved timing exception, supplementation, rejection and cancellation. The review view identifies the version and authorized decision. D100 has a separate correction entry for approved versions, with evidence, affected records, before/after preview and historical basis.
- **UC09**: Search by permitted identifiers, confirm distinct-person duplicate warnings with reason and show field-specific failures while preserving valid form input. Provide portrait replacement/removal, current image and accessible fallback.
- **UC10/UC11**: Distinguish draft, received, valid and playing effectivity. Present each permitted finding and reason. For transfer/plan changes show old and new clubs, intervals and consequences before confirmation. For D057 show the exact reviewed baseline, related references and per-segment historical findings where applicable. Present approve, return for supplementation and reject to the independent decision-maker. Show the returned/rejected outcome while retaining the existing official decision.
- **Failure and security**: Explain Closed, missing/unavailable rules, discontinued new-use master, permission loss and stale version separately. Reload/review after conflicts. Expired or invalid sessions follow the foundation sign-in flow without automatic write replay. Preserve current committed data when a user abandons an edit or cancels confirmation.
- **Acceptance presentation**: Actual Chrome/Edge, Vietnamese diacritics, desktop administration and applicable TT-02 responsive views. Paginate lists over 20 without skipped or duplicated rows for a stable dataset. Keep restricted content out of access-denied displays, client history and public views.
