# ADR 0023 - Shared REST transport and response contract

**Status:** accepted. **Decision:** D085. The Team Leader selected Q85 option A ("Tôi chọn A."), approving the full common package. Authoritative policy is owned by [D085](../../context/english/design/architecture.md#d085---shared-rest-transport-and-response-contract); derived per-UC route/DTO tables live in the owning UC documents.

Choose a project-wide JSON envelope for successes and errors rather than direct resource successes with RFC 9457 errors. This makes React-side handling uniform, accepting responsibility for maintaining the project convention. Use /api/v1, typed allowlisted requests, explicit business command routes, consistent UUID/date/UTC representations, stable pagination and meaningful HTTP statuses. requestId tracing remains distinct from command idempotency. Public/internal fields are server-controlled; downloads are binary exceptions and errors do not expose secrets or internal diagnostics.

HTTP semantics were checked against [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html); the alternative is [RFC 9457](https://www.rfc-editor.org/rfc/rfc9457.html). Exact endpoint dictionaries and per-role/validation/lock/error details are derived technical design, with genuine missing decisions retained in the open register. No client-generation library, code, Feature Specification or whole-v2 approval is established.

## Q96 - Execution, security and concurrency contracts

**Status:** accepted. **Decision:** D096. **Approver:** Team Leader. The Team Leader explicitly selected Q96 option A and the entire proposed package, then requested a pause before Q97 for remaining-question count and a diff-based commit message. [D096](../../context/english/design/architecture.md#d096---api-execution-synchronized-csrf-and-transaction-contracts) owns shared contracts; each owning UC file contains its derived execution authority matrix.

Choose PostgreSQL-backed synchronized CSRF over signed double-submit cookies, fitting existing stateful sessions at the cost of managing prelogin context state. The approved package includes 32-byte random base64url session/CSRF values, SHA-256-only session persistence, HTTPS host-prefixed cookies, stable session CSRF plus 15-minute prelogin context, header/exact-origin validation, explicit request/version/authority allowlists, UUID Idempotency-Key and content/target-bound SHA-256 receipts, ordered lock groups/final authorization, atomic official/projection/review/audit changes and unchanged D084 retry limits. It also specifies unmodified Unicode-code-point/UTF-8 passwords, Argon2id 19 MiB/2 iterations/parallelism 1, persistent rolling D081 username/IP controls and trusted-proxy handling. This concretizes existing business rights rather than expanding roles or delegation. Q97 libraries/blocklist/environment/runtime settings and whole-package approval remain open; no code, generated Specs/Tasks, Issues, commit or push is authorized.
